# DSH-MOBILE Link protocol v1

This is the wire protocol used by the PC side and the Android side of
DSH-MOBILE Link. It only moves DSH session JSONL files; it does not expose
credentials, plugins or workspace files.

## Roles

- **Server**: the side that owns the sessions directory and listens on TCP.
- **Client**: the side that initiates the HTTP requests.

Both sides can be a server. The common deployment is:

```
Phone (client)  ──HTTP/HTTPS──▶  PC (server, 3091)
PC (client)     ──HTTP────────▶  Phone (server, 3090)
```

## Authentication

Every request carries:

```
x-dshm-sync: <password>
```

The password is generated by the server UI/launcher. It is independent from
the DSH Web UI browser session. The reference servers also implement rate
limiting on the Web UI login page, but the sync header itself should be treated
as a bearer secret.

For public Cloudflare tunnels use HTTPS. For a trusted LAN HTTP is allowed, but
the Android host must opt in to cleartext traffic.

## Endpoints

### `GET /__dshm/sync/ping`

```json
{"ok": true, "version": 1, "root": "sessions"}
```

### `GET /__dshm/sync/manifest`

Returns every `sessions/**/*.jsonl` file:

```json
{
  "version": 1,
  "root": "sessions",
  "count": 2,
  "totalBytes": 1234,
  "files": [
    {
      "path": "workspace-key/session-id.jsonl",
      "size": 1234,
      "mtimeMs": 1794361497686,
      "sha256": "..."
    }
  ]
}
```

- `path` is POSIX-style and relative to the sessions root.
- Hidden files and `.tmp` files are skipped.
- `sha256` is lowercase hex.

### `GET /__dshm/sync/file?path=<urlencoded>`

Returns the raw file bytes (`application/x-ndjson`). The server must reject
paths outside the sessions root.

### `PUT /__dshm/sync/file?path=<urlencoded>`

Writes the request body atomically (temp file + rename). Maximum body:
64 MiB. The server creates parent directories.

## Sync algorithm

```
manifestLocal  = walk(localSessions)
manifestRemote = GET manifest
for path in union(local, remote):
  if both and sha256 equal: skip
  if only remote and direction != push: download
  if only local and direction != pull: upload
  if both differ:
    if local is a byte-prefix of remote: download remote
    else if remote is a byte-prefix of local: upload local
    else:
      back up local copy
      newer mtime wins (default), or keep local
```

DSH session logs are append-only JSONL, so prefix detection handles the normal
"one device continued the session" case without conflicts.

## Security

- A DSH session can contain shell commands, file contents and model output.
  Treat the whole sync channel as sensitive.
- Do not expose port 3091 directly to the Internet.
- Public Cloudflare quick tunnels require a long password; the URL itself is
  public.
- Never put passwords or tokens into a git repository.
